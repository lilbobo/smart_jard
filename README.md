# Smart Jard (تطبيق الجرد الذكي) 📦📱

A robust offline-first inventory management and barcode scanning application built with **Flutter & Dart**. Designed for retail and warehouse operations to perform fast stocktaking, manage item counts, and synchronize inventory data efficiently.

## ✨ Key Features (المميزات الرئيسية)

- 🔍 **Barcode & QR Scanning:** Fast and reliable barcode reading for instant product lookup and stock counts.
- 📋 **Inventory Auditing (الجرد الفعلي):** Streamlined interface for recording, updating, and reviewing stock inventory lists.
- 💾 **Offline-First SQLite Architecture:** Operates completely offline with persistent local database operations via `sqflite`.
- 🔐 **Device Activation System:** Built-in licensing and terminal code activation workflow.
- 📊 **Local Data Management:** Add, edit, filter, and audit item records seamlessly.

---

## 🛠️ Tech Stack & Tools (التقنيات المستخدمة)

- **Framework:** Flutter (Channel stable)
- **Language:** Dart
- **Database:** SQLite (`sqflite` / Local helper)
- **Architecture:** Modular MVC/Service pattern (Screens, Services, Database)
